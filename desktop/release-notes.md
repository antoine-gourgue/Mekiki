## Corrections

- Vendeurs bloqués à tort : Mekiki bloquait un vendeur pour une seule évaluation négative
  (1 sur 24, par exemple), alors que Neokyo achète chez lui sans problème. Ces vendeurs sont
  débloqués. Seul un vendeur vraiment mal noté (au moins 20 % d'évaluations négatives) est
  encore écarté ; pour les autres, la fiche indique simplement le nombre d'évaluations
  négatives.
- Le bouton « Vendeur bloqué sur Neokyo » ressemblait à un état alors que c'était une action :
  il s'appelle maintenant « Bloquer ce vendeur (refusé par Neokyo) ».
- Dans la fiche d'une annonce vendue ou retirée depuis la recherche, « Acheter via Neokyo »
  est désactivé (« Plus en vente ») : Neokyo répondait « The given url return not results ».

## Changements

- Vendeurs Rakuma : Mekiki lit le vendeur sur la page de l'annonce Rakuma, remplace dans le
  colis proposé les cartes d'un vendeur qui refuse les intermédiaires ou que vous avez bloqué,
  et le bouton de blocage marche aussi sur Rakuma.
